# LogiFlow Marcaje

Android app for employee attendance tracking.

## Download

Get the latest APK from **[Releases](https://github.com/jvelezp13/logiflow-marcaje-releases/releases/latest)**.

## Install

1. Download `logiflow-marcaje-X.Y.Z.apk` on your Android phone.
2. Open it and allow installation from unknown sources if prompted.
3. If you already have the app, installing the new APK updates it and keeps your data.
